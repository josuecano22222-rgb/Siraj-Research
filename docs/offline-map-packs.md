# Local raster map packs

SIRAJ Explorer and the generic coordinate picker can optionally serve trusted raster MBTiles from the site's private storage as **Local standard** and **Local aerial** basemaps. This does not bundle street maps or satellite imagery: coverage, dates, resolution and rights depend entirely on the administrator-supplied packs. The built-in Natural Earth world overview remains the default. Map packs are served from the local Frappe site, not the public internet; users still need a connection and login to that server. The optional OpenStreetMap layer is separate and continues to disclose a viewer's IP and viewed area to that provider.

## Pack preparation and permissions

An administrator may provision `standard.mbtiles` and/or `aerial.mbtiles` in the site's `private/siraj_maps` directory after reviewing licensing, coverage and the files' provenance. Do not put private or licensed imagery in Git, public assets, or an untrusted upload path. This version has **no upload, remote-fetch, pack-management or installation command**. Packs must be completely written and SQLite-checkpointed before use and must not be modified in place while served. Back them up separately and replace atomically during a maintenance window. The current reader accepts only PNG, JPEG or WebP raster MBTiles with TMS rows, a concrete `tiles` table and a non-partial unique `(zoom_level, tile_column, tile_row)` index; vector tiles, `tiles` views and XYZ-row databases are not supported. Metadata may supply attribution and zoom limits. A pack that fails these checks is not offered as a layer. Image signatures are checked, not complete image integrity; SQLite files must come from a trusted administrator.

All map-pack metadata and tile requests require a logged-in user with read permission for `Place`. This is a shared pack permission, not per-record or per-geographic-region access control. The site owner must confirm this sharing is appropriate for licensed or sensitive imagery. Responses use private, no-store caching; tile requests have a rate limit, but high concurrency and large packs still require capacity testing. The server never accepts arbitrary file paths or URLs; it uses two fixed names within the selected site's private map directory and rejects symlinked packs and pack directories. Attribution is escaped before being shown in the Explorer and coordinate picker. Tile errors or missing coverage are reported instead of switching to an online service.

## Select and download a local area in Explorer

Downloads are **disabled by default**. Once licensing and security are reviewed, an administrator can opt in individual installed packs through the site's `site_config.json`, for example `"siraj_offline_map_downloads": ["standard", "aerial"]`. Do not set this option merely because data is present: confirm redistribution rights for each pack and permission to store it on disconnected devices. An absent or non-list setting enables neither pack. Configuration changes may require a web-worker restart. No schema migration, pack upload, network fetch, or provider scraping is involved.

In Geographic map, choose an enabled local pack, open **Download local area**, select **Use current map area** or enter west, south, east, north, and zoom bounds; estimate the possible tiles before downloading. West greater than east crosses the antimeridian. Zooms must be within the source pack's advertised limits. The ZIP is assembled in the browser by individually requesting existing local tiles. It contains only basemap imagery, attribution and the standalone viewer—no SIRAJ records. A request is limited in the interface to 512 possible tiles and 16 MiB of tile payload, with additional browser memory and ZIP overhead; absent tiles are skipped and reported. Cancel stops further tile requests. The package is unencrypted and remains accessible after server permission changes; it cannot be revoked. Store it only on authorized devices, use secure transfer and delete it according to policy. Browser and device policies may prevent downloads, extraction or local-file access.

The download opt-in controls the provided UI, **not access to tiles or a hard security quota**. Every Place reader can already retrieve and save individual tiles regardless of the opt-in. Do not install a pack if sharing it with all Place readers is inappropriate. Per-IP tile rate limits can affect shared networks and are not a global concurrency, disk, bandwidth or per-user quota; users can make additional requests outside the UI. Requests reveal viewed and downloaded tiles to the server and may be recorded in server/proxy logs. Capacity and logging/privacy policies must be reviewed before enabling. Offline packages are snapshots; updates, remote wipe, device encryption and record synchronization are not provided.

## Administrative offline package prototype

An administrator can build a **basemap-only** ZIP from a trusted, licensed local raster pack using the Python module below. This is a local command, not a Frappe API; the separate Explorer workflow above is more tightly bounded. Bounds are west, south, east, north in degrees, limited to Web Mercator (approximately ±85.0511° latitude); west greater than east crosses the antimeridian. The output must not already exist. Example only, with paths and bounds chosen by the administrator:

```sh
python -m siraj_research.utils.offline_viewer /private/path/aerial.mbtiles /private/path/area.zip \
  --bounds 43 32 45 34 --minzoom 4 --maxzoom 10 --confirm-redistribution-rights
```

The explicit flag is the administrator's confirmation that the source license permits distribution to disconnected devices. Confirm permitted area, resolution, retention and required attribution before creating or sharing any package. This command does not download imagery and must never be used to scrape public tile services. The source and output paths must be protected; the ZIP contains imagery in ordinary unencrypted files. Share only with authorized people using an approved secure transfer, and protect the extracted files and device. Temporary SQLite files are created in the operating system's temporary directory, whose storage and backups must also be suitable for the imagery. Interrupted or killed processes may leave temporary or partial files for an administrator to remove securely. No automatic revocation or expiry is provided.

Extract the ZIP completely and open `index.html` on the device. The viewer pans and zooms, fits the selected area, accepts decimal coordinates (including Arabic and Persian digits), shows clicked coordinates, and provides approximate distance and polygon-area measurements with undo and clear. Measurements use spherical approximations, are not survey-grade, and may be misleading for very large or self-intersecting polygons; changing modes clears the current geometry. The interface supports English and Arabic; it does not contain or sync SIRAJ records, edit them, or provide the Explorer's measurement and analysis tools. It makes no intentional internet requests. It uses local Leaflet assets and packaged tile images; some browsers or device policies may restrict local files, and mobile behavior has not been verified. Missing tiles produce empty areas. Tile availability and resolution depend on the provided pack, and a requested area can contain only partial coverage. The package contains no generalized fallback unless that fallback is included in the supplied tiles.

Exports are limited to 25,000 possible tiles and 200 MiB of actual tile payloads, with additional disk space needed for SQLite, the ZIP, extraction, and filesystem overhead. These are not full disk, time, concurrency or per-user quotas. Package creation is synchronous and is not intended to run concurrently on a live Frappe web worker. It is not a sandbox for malicious databases or an authorization layer. **There is no disconnected Explorer with records.** Do not expose this tool as a web endpoint without a reviewed rights, security, quota, lifecycle and privacy design.

The implementation and security checks have only been tested with SQLite fixtures, simulated Frappe, and synthetic Chromium browser data, but no real Frappe site, real imagery, large pack, mobile device or role matrix has been verified. The unrelated Event collision and coordinate schema migration remain unresolved; this feature does not authorize migration, reinstall or synthetic data insertion. See `docs/event-collision-remediation.md` and `docs/coordinate-map.md`.
