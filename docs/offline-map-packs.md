# Local map-pack groundwork

This is an **internal library**, not a complete map feature. The app does not yet install, serve, browse or download regional packs, and no street or aerial imagery is bundled. The existing local Natural Earth layer is a low-detail world basemap, not aerial imagery. No public web endpoint or installation hook has been added by this component.

`utils/offline_tiles.py` reads trusted, administrator-supplied raster MBTiles (PNG, JPEG or WebP; TMS row numbering) and can create an MBTiles subset for a bounded area and zoom range. It performs no network requests, uses a read-only source connection, validates coordinates and image signatures, rejects duplicate tile keys and unsupported formats, refuses to overwrite destinations, and limits the requested tile count and total tile payload bytes. Source and exported file lifecycle and access controls are the caller's responsibility. Source packs must be fully written and checkpointed before access; the read-only SQLite connection uses immutable mode. The output reports the number of tiles actually present, not just the number geometrically possible. Crossing the date line is supported; standard MBTiles `bounds` is then a conservative global-width envelope and `siraj_requested_bounds` retains the original request.

This library alone does **not** sandbox malicious SQLite files, enforce Frappe permissions, protect against query-resource exhaustion, restrict file paths, verify image integrity beyond signatures, ensure atomic backups, or verify tile licensing. Do not expose it to users or accept arbitrary uploads. Integration requires server-side access checks, site-isolated trusted pack management, safe paths, availability/coverage reporting, resource and concurrent-export limits, attribution handling, a map interface, and real security and Frappe tests. Output size can exceed the tile-payload limit because SQLite has storage overhead. Offline packs may still contain sensitive location data and need an access/retention policy.

Aerial and detailed standard packs must come from sources with clear permission for local storage, area extraction and redistribution. Coverage, resolution, freshness, storage, and whether "offline" means local server or a disconnected end-user device must be settled before the rest can be implemented accurately. Neither the public OpenStreetMap tile service nor any other external service should be bulk-downloaded without permission and compliance with its policy. No aerial coverage is claimed or included here.
